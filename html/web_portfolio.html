Lumin Journal is a real time journal that I built for personal use as my journal. Using Next.js, clerk for authentication and convex as a real-time database, I incorporated the block-based rich text editor, Blocknote as the medium to write the journal entries. I wrote the API endpoints that allow me to create, delete and bookmark my entries, as well as a mood feature, wherein I can assign a mood to each day and it is reflected in real time on the calendar showing my entries.

Spotify Data Visualiser

html

css

javascript

Spotlight is a web application that uses the Spotify Web API to provide users with insights into their music listening habits. The application features a secure OAuth 2.0 authentication flow, allowing users to log in with their Spotify accounts. Once authenticated, users can access their top tracks, recently played songs, and library data. The application uses modern web technologies including Express.js for the backend server, with proper CORS configuration and environment variable management for secure deployment. Key features include token refresh handling, secure storage of authentication tokens, and a responsive user interface. The project is deployed on Render with proper configuration for production environments, including static file serving and secure redirect URI handling.

This project was completed during my internship at the Jamaica Teaching Council government agency. I was tasked with rebuilding their intranet on the wordpress CMS platform to improve task management, communication and workflow efficiency of the employees. The intranet has been completed with features such as a notice board, a google calendar integrated event calendar, a messaging system, a ticket based help desk, a staff directory, document repository and an inventory management system tied to a Caspio database. The look and feel of the website was created from scratch using css and functionality was added to many sections of the website using javascript and php.

Seeker.io is a real-time chat application built with React for the frontend and Socket.io for the backend. The app allows users to generate a uuid that acts as a phone number and communicate with users via their uuid. Users will may contacts and begin conversations with one or multiple contacts. The socket.io server facilitates the communication between chat rooms and conversation data is stored locally.

User flow:
Generate ID > Add contact via another existing ID > New conversation with contact > Message.
